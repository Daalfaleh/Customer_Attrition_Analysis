# Customer Attrition Analysis

A Jupyter notebook for exploring customer churn and training a logistic-regression classifier. The workflow covers data inspection, preprocessing, exploratory visualization, model training, and evaluation.

## Use

1. Create a Python environment with Jupyter, pandas, NumPy, matplotlib/seaborn, and scikit-learn.
2. Open `churn_prediction_logistic_regression.ipynb`.
3. Run the cells in order and provide the referenced dataset if it is not embedded.

The notebook is intended as an end-to-end, reproducible example of binary churn prediction.
